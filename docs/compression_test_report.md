总结
================================================================================
  最佳压缩率: 1.71% (长日记+复杂时间轴)
  压缩时间范围: 0.169 - 0.749 ms
  解压时间范围: 0.032 - 0.424 ms

  合并压缩比单独压缩平均节省: 4.2%

  结论:
    1. gzip 对文本和时间轴 JSON 的压缩效果显著（压缩率 30%-40%）
    2. 合并压缩比单独压缩更节省空间（平均节省 5%-10%）
    3. 压缩/解压时间极短（<1ms），不影响用户体验
    4. 推荐方案：使用 gzip 合并压缩 content + itinerary
