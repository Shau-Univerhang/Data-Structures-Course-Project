================================================================================
总结
================================================================================

推荐配置:
  - 视频编码: H.265 (HEVC)
  - CRF 值: 28（平衡质量和体积）
  - Preset: fast（平衡速度和质量）
  - 音频编码: AAC 128k
  - 像素格式: yuv420p（最大兼容性）

预期效果:
  - 视频体积减少 40%-50%
  - 编码速度约 0.4s/10MB（fast preset）
  - 画质损失肉眼不可见
  - 主流浏览器兼容播放
